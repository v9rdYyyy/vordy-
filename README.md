# Сборник — Discord бот для сборов

Готовый бот на `discord.py` для создания и ведения сборов через команду `/сбор`.

## Что умеет

- Команды `/сбор`, `/логи` и `/стоплоги` доступны администраторам сервера и ID, которые указаны в `sbornik_bot/bot.py`.
- Создание сбора с обязательными параметрами:
  - название
  - дата/время мероприятия
  - основные слоты
- Необязательные параметры:
  - доп. слоты
  - роли
  - комментарий
  - создание ветки
  - изображение
- Публичная панель сбора с кнопками:
  - `Присоединиться`
  - `Присоединиться к доп. слоту`
  - `Покинуть`
  - `Отметиться`
  - `Управление`
- Автоматическое распределение в:
  - основу
  - доп. слоты
  - резерв
- Отметка участника галочкой `✅`.
- Панель управления для модераторов сбора:
  - выгнать участника
  - переместить между основой / доп. слотами / резервом
  - закрыть сбор с тегом
  - закрыть сбор бесшумно
  - выбрать войс
  - напомнить участникам в ЛС
  - добавить модератора
  - удалить модератора
- Хранение данных в SQLite.
- Отдельный канал логов по команде `/логи`.
- Команда `/стоплоги` полностью отключает отправку логов по сборам на сервере.
- После перезапуска бота кнопки продолжают работать для активных сборов.

## Важные замечания

1. В Discord нельзя сделать так, чтобы одна и та же кнопка в публичном сообщении физически отображалась только для части пользователей. Поэтому кнопка `Управление` видна всем, но пользоваться ей могут только:
   - создатель сбора
   - добавленные модераторы
   - администраторы сервера

2. Интерфейс создания сделан через slash-команду `/сбор` с параметрами. Это рабочий и стабильный вариант для Discord API.

3. Поле `роли` в slash-команде вводится строкой. Поддерживаются:
   - упоминания ролей: `@роль1 @роль2`
   - ID ролей
   - точные названия ролей через запятую

## Установка

### 1. Установите Python
Рекомендуется Python **3.11** или **3.12**.

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Создайте `.env`
Скопируйте файл `.env.example` в `.env` и заполните его.

Пример:

```env
DISCORD_BOT_TOKEN=ваш_токен_бота
DISCORD_GUILD_ID=123456789012345678
BOT_TIMEZONE=Europe/Moscow
```

`DISCORD_GUILD_ID` не обязателен, но с ним команда `/сбор` появляется быстрее на тестовом сервере.

Пользователей, которым тоже разрешено использовать `/сбор` без прав администратора, можно указать прямо в `sbornik_bot/bot.py` в константе `ALLOWED_CREATE_COMMAND_USER_IDS`.

## Какие права нужны боту

На сервере желательно выдать боту права:

- Send Messages
- Embed Links
- Use Slash Commands
- Read Message History
- Send Messages in Threads
- Create Public Threads
- Manage Threads
- View Channels

Для выбора войсов и отправки ссылок на них отдельные специальные права обычно не нужны, если бот видит канал.

## Как пользоваться

### Команда `/логи`

Включает отправку логов по сборам в текущий канал. В логах фиксируются:

- кто зашёл в основу / доп. слоты / резерв
- кто вышел из основы / доп. слотов / резерва
- кого и куда переместили между списками
- кого модератор выгнал из сбора

### Команда `/стоплоги`

Полностью отключает отправку логов по сборам на сервере, пока кто-то снова не выполнит `/логи`.

### Команда `/сбор`

Параметры:

- `название` — обязательно
- `дата` — обязательно
- `слоты` — обязательно
- `доп_слоты` — не обязательно
- `роли` — не обязательно
- `комментарий` — не обязательно
- `создать_ветку` — не обязательно
- `изображение` — не обязательно

### Примеры

#### Простой сбор

- название: `КАПТ`
- дата: `08.03.2026 19:00`
- слоты: `35`

#### С дополнительными параметрами

- название: `КАПТ В СЕНЗА`
- дата: `завтра 19:30`
- слоты: `35`
- доп_слоты: `15`
- роли: `@роль1, @роль2`
- комментарий: `капт`
- создать_ветку: `True`
- изображение: прикрепить картинку

## Логика записи

- Кнопка `Присоединиться`:
  - сначала записывает в основу
  - если основа заполнена, переводит в доп. слоты
  - если и там мест нет, отправляет в резерв

- Кнопка `Присоединиться к доп. слоту`:
  - записывает в доп. слоты
  - если доп. слоты заполнены, отправляет в резерв

- `Покинуть` удаляет пользователя из любого списка.
- `Отметиться` ставит или снимает галочку у ника.

## Модераторы сбора

- Создатель сбора всегда имеет полный доступ.
- Администратор сервера тоже может управлять сбором.
- Дополнительных модераторов можно назначать через кнопку `Управление` → `Добавить модератора`.
- Удалять добавленных модераторов может только создатель сбора.

## Частые проблемы

### Команда `/сбор` не появляется

Подождите 1–5 минут для глобальной синхронизации.

Либо укажите `DISCORD_GUILD_ID` в `.env`, тогда команда появится на выбранном сервере почти сразу.

### Не создаётся ветка

Проверьте права бота:

- `Create Public Threads`
- `Send Messages in Threads`
- `Manage Threads`

### Напоминания в ЛС приходят не всем

Некоторые пользователи могут запрещать личные сообщения от участников сервера. В таком случае бот покажет число успешных и неуспешных отправок.
